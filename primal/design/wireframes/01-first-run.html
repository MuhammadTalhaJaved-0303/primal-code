01 — First run: DMG open to first agent edit

Story 1 — "Install and make my first edit" · target ≤ 60 s from DMG open, measured to the first file the agent writes.
Maps to primal/make-dmg.sh (ad-hoc signature, no Developer ID) · contrib/primalBoot (boot overlay ≤ 1.4 s) · contrib/primalStart/browser/primalStartEditor.ts (Start page; FIRST RUN strip from the parallel first-run branch: computeFirstRunGuide, PrimalFirstRunStrip; MOTIF row from PR #23: primalStartMotifRow.ts, command primalCode.motif.pick) · contrib/chat/browser/primalSettings/primalSettingsEditor.ts (command primalCode.manageProviders) · contrib/workspace (Restricted Mode banner, upstream) · contrib/chat/browser/agentSessions/agentHost/agentHostDownloadProgress.ts ("Downloading {0} agent") · product.json agentSdks (SDK fetched at runtime).
Monochrome rule: state is written in words; nothing here relies on hue.
